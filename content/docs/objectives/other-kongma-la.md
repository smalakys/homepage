## Description

Kongma La is the highest of the Three Passes Trek crossings in the Khumbu, linking the Chhukung valley with Lobuche. It provides a remote alternative to the main Everest Base Camp trail.

The standard crossing goes between Chhukung and Lobuche via a long moraine and high-pass day. It is a trekking route with no technical summit climb, though fresh snow can obscure the route.
