## Description

Lagginhorn is a largely rock-based Pennine four-thousander above Saas-Grund, unusual for a normal route that can avoid glacier travel in favourable conditions. Its long south ridge is a classic.

The Weissmies Hut is the customary base for the normal west-south-west ridge. The north ridge is a longer, more technical alternative.
